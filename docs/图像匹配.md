# 图像匹配
代码在[这里](https://github.com/i2w3/ChangeDetection/blob/master/test_matcher.py)，默认使用 `./res/data/UAV_CD/demo4` 来展示。

环境要求：
```
pip install opencv-python matplotlib
```

```bash
python test_matcher.py <method> [-dp dataset_path] [-sn sample_name] [--enable_cuda] [--num_features N]
```

支持的方法包括：`SIFT`、`ORB`、`AKAZE`，而 `ORB[CUDA] 和 `SUFT` 需要自己构建 opencv，可参考[build_opencv](https://github.com/i2w3/build_opencv)
