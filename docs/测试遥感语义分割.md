# EMOT
[EMOT](https://github.com/tue-mps/eomt) 源自 CVPR 2025 Highlight <Your ViT is Secretly an Image Segmentation Model>，训练脚本来自[lightly-train](https://github.com/lightly-ai/lightly-train)(`这个代码库工程化做的好，支持导出 onnx + tensorRT`)，需要先用 DinoV2 的方式在 EarthVQA 的测试集上预训练一个 Vit 做为主干，再用来训练 EMOT。目前训练了 vit-t16 和 vit-s16 

| Implementation | Model                       | Val mIoU | Avg. Latency (ms) | Params (M) | Input Size |
| -------------- | --------------------------- | -------- | ----------------- | ---------- | ---------- |
| LightlyTrain   | dinov3/vitt32-eomt-coco     | 34.0     | 4.2               | 6.0        | 512×512    |
| LightlyTrain   | dinov3/vitt32plus-eomt-coco | 36.0     | 4.4               | 7.7        | 512×512    |
| LightlyTrain   | dinov3/vits32-eomt-coco     | 42.4     | 5.4               | 21.6       | 512×512    |
| LightlyTrain   | dinov3/vitb32-eomt-coco     | 48.3     | 9.4               | 85.7       | 512×512    |
| LightlyTrain   | dinov3/vitl32-eomt-coco     | 51.2     | 17.5              | 303.2      | 512×512    |
| LightlyTrain   | **dinov3/vitt16-eomt-coco** | 37.9     | 6.0               | 6.0        | 512×512    |
| LightlyTrain   | dinov3/vitt16plus-eomt-coco | 39.5     | 6.4               | 7.7        | 512×512    |
| LightlyTrain   | **dinov3/vits16-eomt-coco** | 45.0     | 11.3              | 21.6       | 512×512    |
| LightlyTrain   | dinov3/vitb16-eomt-coco     | 50.1     | 23.1              | 85.7       | 512×512    |
| LightlyTrain   | dinov3/vitl16-eomt-coco     | 52.5     | 49.0              | 303.2      | 512×512    |

| EoMT_vits16 | 0.411s | 0.049s |
| EoMT_vitt16 | 0.311s | 0.040s |

## 训练代价
EMOT的训练要求较高，下面是 vit-s16 在 512 * 512，32 batch_size, bf16 精度下的内存占用，耗时半天
```bash
[4] NVIDIA A800 80GB PCIe | 52°C,  69 % | 26221 / 81920 MB | lxb(26198M) root(4M)
[5] NVIDIA A800 80GB PCIe | 55°C,  87 % | 26222 / 81920 MB | lxb(26198M) root(4M)
``` 

用 dinov2 的方式预训练一个 vit-s (224 * 224，256 batch_size, bf16, 都是预训练一天就拿去训练 eomt 了，完整跑完至少要3天)同样要求较高：
```bash
[0] NVIDIA A800 80GB PCIe | 34°C,   5 % | 41897 / 81920 MB | lxb(41874M) root(4M)
[1] NVIDIA A800 80GB PCIe | 36°C, 100 % | 41890 / 81920 MB | lxb(41866M) root(4M)
```
